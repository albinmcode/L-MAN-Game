# L-Man
Versión alternativa al videojuego de Pac-Man, pero orientado hacia la práctica del inglés, mediante un sistema de recolección de letras que servirán como traducción para una palabra propuesta durante el tiempo de juego. Al iniciar el juego se mostrará una palabra en español, y un laberinto lleno de letras repartidas alrededor del mapa. El jugador deberá recolectar solamente las letras que logren formar la traducción, antes de que se le acabe el tiempo, además tendrá que enfrentarse a caracteres inválidos que le perseguirán, esto simulando a los fantasmas de Pac-Man.
